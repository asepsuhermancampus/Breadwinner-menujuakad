# Linked partner onboarding implementation plan

**Goal:** Lock the unconnected partner profile, invite by link, let the authenticated partner complete their profile and collaborate in the owner's workspace with separate personal savings permissions.

**Architecture:** Existing owner/partner membership remains the source of access. Each account edits its own profile slot, invitations expire and are single use, and accepting the invitation writes membership plus partner profile atomically. Revocation removes access, hides the disconnected profile and invalidates invitations, preserving financial history. Membership and saved couple sides determine manual savings permissions on the server. Shared budget allocations retain the previously authorized ability to use either fund.

**Tech stack:** Next.js App Router, React, SQLite, Vitest, Playwright.

## Contract and decisions

- `CustomerWorkspace.partnerAccess` contains `state: locked | invited | connected`, optional expiry. Unknown/legacy disconnected partner data is hidden rather than deleted from storage. Historical finance entries remain intact.
- An owner may share an invitation immediately, including before completing their profile or choosing groom/bride. When a side is known the partner is automatically assigned the other side; otherwise finance still requires a one-time position claim before manual transactions. Server rejects cross-side manual additions and withdrawals.
- The API uses the authenticated active workspace. A profile PATCH submits only the current viewer's full name and nickname, plus owner side for owners. Owner edits owner slot, partner edits partner slot; photo mutations follow the same ownership.
- Invitation creation returns a token/expiry; UI presents an absolute `/join/<token>` link with copy/open actions. No messages are sent automatically.
- A valid invitation requires the recipient to sign in/register and complete only full name/nickname. Successful submission shows a copyable account link and a direct button to Profil & Akses for photo upload. Later sign-ins default to the parent's shared workspace and subscription.
- Linked partner can use shared planning features under the owner's entitlement, but cannot invite/revoke another member or change the owner's profile. Revoked recipients lose server access immediately and the open client reloads on membership invalidation checks.
